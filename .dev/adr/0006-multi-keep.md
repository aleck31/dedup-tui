# ADR-0006 多保留模型：每副本独立 keep/drop，强制 ≥1

- **状态**: Accepted
- **日期**: 2026-06
- **取代**: 早期的“单 keeper 索引”模型

## 背景

同一内容有时需要在多个位置各留一份。最初的“每组只能选一个 keeper”无法表达。

## 决策

状态从“单 keeper 索引”改为“每组每副本一个 keep/drop 布尔标记”+ 组内光标。可同时保留多个；尝试取消最后一个 keeper 会被拒绝。

## 影响

- 支持“同内容留多份”的真实场景。
- `≥1` 强制是安全底线：绝不把一组全删光（apply 时 keepers 为空则跳过整组）。
