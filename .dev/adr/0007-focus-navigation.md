# ADR-0007 交互模型：焦点切换 + 焦点内上下移动

- **状态**: Accepted
- **日期**: 2026-06
- **取代**: 早期的“↑↓选组 / ←→在副本间切 keeper”组合键模型

## 背景

双栏 TUI（左=组列表，右=组内副本）需要一套清晰的键位。

## 决策

- ↑/↓ 移动**当前焦点面板**内的行（左=选组，右=选文件）。
- ←/→ 在左右两栏间切换焦点。
- space 切换当前文件 keep/drop。
- WASD 为无方向键键盘的等价 fallback；q / Esc 退出。
- 焦点面板高亮。

## 影响

- 符合标准双栏 TUI 直觉：“焦点决定上下移动谁，左右只管切焦点”。

## 踩坑记录

早期组合键模型里 ←→ 会被 DataTable 内置水平滚动吞掉，需在 `on_key` 里拦截。新模型语义更清晰，也顺带解决了这个冲突。
