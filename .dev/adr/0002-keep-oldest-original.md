# ADR-0002 “最原始”副本判定：创建时间优先，跨平台分级

- **状态**: Accepted
- **日期**: 2026-06

## 背景

每组重复需要一个默认保留项。用户语义上的“原始版本”= 最早创建的那份。但“创建时间”在三平台语义不同。

## 决策

默认 keeper = 创建时间最早；并列取修改时间最早；再并列取路径最短。创建时间按平台取：

- macOS: `st_birthtime`
- Windows: `st_ctime`（Windows 上即创建时间）
- Linux: 有 `st_birthtime` 用之，否则退回 `st_mtime`

## 影响

- 跨平台一致地选出“最早”的副本作默认保留。
- Linux 多数文件系统经 `os.stat` 拿不到 birthtime，必须降级，否则会静默用错时间——已显式处理。
