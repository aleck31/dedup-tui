# ADR-0004 删除 = 移到隔离区 + 删前重新哈希校验，绝不直接 rm

- **状态**: Accepted
- **日期**: 2026-06

## 背景

删除类工具的底线是不可误删、不可逆丢数据。

## 决策

被移除文件 `shutil.move` 到 `~/dedup-quarantine/<原始路径>`（保留完整路径结构，可恢复）。移动前对每个 victim 重新哈希与 keeper 比对（目录则逐文件比对），不一致则跳过。`--no-verify` 可关闭校验换速度。

## 影响

- 一切可恢复：误判可从隔离区移回。
- 删前 re-hash 防止“扫描后文件被改/被换”导致误删非重复内容。
- 隔离区会占空间，需用户自行清理（等同于二次确认）。
